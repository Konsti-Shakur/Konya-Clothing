# Konya Clothing V2 — allgemeine Clothing-Plattform

Diese Version ist auf allgemeine Clothing-Aufträge ausgerichtet, nicht auf Fraktionsverwaltung.

## Neu
- Fraktionen als Hauptbereich entfernt
- Kundenverwaltung eingeführt
- Organisation/Fraktion nur optionales Kundenfeld
- Öffentliche Startseite
- Auftrag-anfragen-Formular
- Showcase
- Kundenbereich mit Auftragsstatus und Freigabe
- Allgemeine Leistungen: Hoodie, Hose, Shirt, Weste, Komplett-Outfit, Texture Fix, Logo Platzierung, Sonderanfertigung

## Hinweis
Die aktuelle Version speichert Daten noch lokal im Browser (`localStorage`).
Für echten Mehrbenutzerbetrieb auf Railway ist als nächster Schritt ein Backend + PostgreSQL nötig.
